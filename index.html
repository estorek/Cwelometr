Zarządzaj bazą danych na GitHub Pages (Eksportuj, importuj nową wersję JSON lub zresetuj stan)

Jak opublikować zaktualizowane dane na stałe dla wszystkich odwiedzających stronę na GitHub Pages?

  1. Dodaj wypowiedzi lub zaimportuj nowy zestaw danych w przeglądarce.
  2. Kliknij przycisk "Eksportuj JSON" i pobierz plik z danymi.
  3. Otwórz kod pliku index.html i zastąp tablicę defaultQuotes nową zawartością pliku JSON.
  4. Wyślij plik na repozytorium GitHub (git commit & push). Strona zostanie natychmiast zaktualizowana dla każdego!
